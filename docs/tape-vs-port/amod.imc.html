2#FILE AMOD -- ASSEMBLY MODULE FOR NEW IMP.
3 THE ASSEMBLER MAKES THREE PASSES THRU THE CODE:
4 PASS 1: COUNT REGISTER REFERENCES
5 PASS 2: ALLOCATE REGISTERS, INSERT REGISTER SAVES & RESTORES, DEFINE TAGS,
6 COUNT INSTRUCTIONS, SUPPRESS REGISTER LOADS (WHEN PERMITTED),
7 AND MARK REFERENCES TO VARIABLES OR LONG CONSTANTS BY SETTING
8 THE DIR PROPERTY "ATYPE" TO 6.
9 PASS 3: PUT OUT THE OBJECT CODE
10 BETWEEN THE SECOND AND THIRD PASSES, STORAGE IS ALLOCATED FOR VARIABLES.
12 /A PROVIDES AN ASSEMBLY LISTING.
13 /B TURNS ON DEBUGGING PRINTOUT AND LISTING.
15 THE FORMATTING OF THE OBJECT PROGRAM IS DONE IN FILE "OMOD" (OUTPUT MODULE).
