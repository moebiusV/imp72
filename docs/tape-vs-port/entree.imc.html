68 THE PARSER OUTPUT IS GENERATED BY PARSING AN INSTANCE OF THE PRODUCTION
69 BEING PROCESSED. IT CONTAINS IDENTIFIERS OF THE FOLLOWING FORMS:
71 REGNNKK NN,KK DECIMAL DIGITS - WILL MATCH A REGISTER
72 BETWEEN NN AND KK.
73 REGNN SAME AS REGNNNN
74 REG MATCHES ANY REGISTER.
75 CONMMKK MATCHES A CONSTANT IN MM BITS SHIFTED KK BITS LEFT.
76 CONMM SAME AS CONMM00
77 CON MATCHES ANY CONSTANT
78 CNG USED SAME AS CON, BUT FOR NEGATIVE CONSTANTS.
79 VAR MATCHES ANY CONSTANT OR SIMPLE VARIABLE
80 MEM MATCHES ANY SUBSCRIPTED VARIABLE.
81 FLT ONLY FLOATING POINT MAY MATCH
82 IGR ONLY FIXED POINT MAY MATCH
83 BYT (IMP11) ONLY ATYPE BYTE WILL MATCH
84 NAM MATCHES A RAW IDENTIFIER.
85 WRD (IMP10) ONLY 1 WORD OF CODE MAY MATCH.
86 NSE (IMP11) ONLY NO-SIDE-EFFECTS MAY MATCH.
88 AN IDENTIFIER WITHOUT MODIFIERS MAY MATCH ANY OF THE ABOVE.
89 THE PROPERTIES FLT AND IGR ARE ORTHOGONAL TO THE OTHERS.
90 THE PROPERTY WRD IS ORTHOGONAL TO THE OTHERS.
91 A REGISTER MATCHES THE SPECIFICATIONS ONLY WHEN IT IS FORCED, WHEN
92 EVENTUALLY ALLOCATED, TO FALL WITHIN THE SPECIFIED LIMITS.
93 AN IDENTIFIER WHICH MAY MATCH MORE THAN ONE OF THE ABOVE MAY BE MADE
94 BY CATENATING THE APPROPRIATE IDENTIFIERS - E.G.,CON18REG0115.
95 IN ADDITION, ANY IDENTIFIER NOT CONTAINING THE CHARACTER 0 MAY
96 APPEAR. IF AN IDENTIFIER APPEARS MORE THAN ONCE, SUBSEQUENT OCCURRENCES
97 WILL BE REQUIRED TO MATCH THE FIRST OCCURRENCE EXACTLY (I.E., SAME
98 EXPRESSION). MODIFIERS ARE NOT ALLOWED ON THE SUBSEQUENT OCCURRENCES

100 >>MUST<< APPEAR ON EVERY OCCURENCE OF IT.
