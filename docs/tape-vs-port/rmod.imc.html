2#FILE: RMOD -- REGISTER ALLOCATING MODULE FOR NEW IMP.
4THIS MODULE REFERENCES TWO VECTORS, RST AND RSV (LENGTHS ARE NRST),
5WHICH KEEP TRACK OF REGISTER STATES AND VALUES.
7 RST[I] REPRESENTS THE STATE OF REGISTER I:
9 !-- ! ---- ! - ! - ! - ! - ! - ! - ! ---!
10 !TT ! RX ! S ! R ! D ! T ! M ! U ! CNT!
11 !-- ! ---- ! - ! - ! - ! - ! - ! - ! ---!
12NO. OF BITS: 6 12 1 1 1 1 1 1 12
14 TT: NUMBER OF THE TEMPORARY IN WHICH THIS REGISTER HAS BEEN SAVED
15 (MEANINGFUL ONLY IF "M" BIT IS ON).
16 RX: POINTS TO THE ELEMENT OF THE REGISTER VECTOR "RG" WHICH
17 RESULTED IN THE ALLOCATION OF THIS REGISTER. THIS INFORMATION
18 NEEDED IF THE REGISTER IS TO BE REASSIGNED.
19 S: 1 IF THIS REGISTER HAS BEEN DECLARED "SCRATCH".
20 R: 1 IF THIS IS A REGISTER WHICH CONTAINS THE RETURNED VALUE OF A FCN.
21 D: 1 IF THIS REFERS TO THE FIRST REGISTER OF A PAIR OF REGISTERS.
22 T: 1 IF THIS IS NOT A TEMPORARY REGISTER - SHOULD BE AVOIDED.
23 M: 1 IF THIS REGISTER HAS BEEN SAVED IN A TEMPORARY (SEE ALSO "TT").
24 U: 1 IF THIS REGISTER CONTAINS A USEFUL VALUE.
25 CNT: NUMBER OF TIMES THIS REGISTER IS REFERRED
26 TO IN THE REMAINING OBJECT CODE.
28 RSV[I] CONTAINS THE VALUE OF REGISTER I IF "USE BIT" IS SET:
29 LEFT HALF = CONSTANT OFFSET, RIGHT HALF = DIRECTORY INDEX.
32FUNCTIONS IN THIS MODULE: (THIS DOCUMENATION IS SOMEWHAT OBSOLETE.
33 THE GENERAL FLOW IS CORRECT, BUT THE DETAILS ARE NO LONGER ACCURATE.)
35 REGVAL(R,OPC,W) R: REGISTER INDEX (I.E., INDEX INTO VECTOR RG)
36 OPC: OPCODE OF CURRENT INSTRUCTION
37 W: DATA WORD OF THIS INSTR. (I.E., WORD
38 WHICH CONTAINS DIR INDEX & CONST PART)
39 VALUE: RETURNS 1 IF THE CURRENT INSTR SHOULD BE
40 SUPPRESSED, ELSE 0.
41 THIS FUNCTION HANDLES THE REGISTER ALLOCATION, ACCORDING TO THE
42 FOLLOWING ALGORITHM:
43 1. IF RG[R]<0 THEN A REGISTER HAS ALREADY BEEN ASSIGNED; THE
44 REGISTER IS -RG[R]. DECREMENT THE REF COUNT IF IT IS NOT
45 ALREADY 0. IF THIS OPCODE CHANGES THE CONTENTS OF THE
46 REGISTER, THEN CLEAR THE "USE BIT". RETURN.
47 2. EXAMINE RG[R] TO DETERMINE THE LOWER & UPPER BOUNDS FOR
48 THIS REGISTER.
49 2.1. IF LOWER BND=UPPER BND, THEN A SPECIFIC REGISTER IS BEING
50 REQUESTED. ALLOCATE THE REGISTER AS IN (4) BUT FIRST EMIT
51 AN ERROR MESSAGE IF THE REGISTER IS CURRENTLY IN USE.
52 3. IF W IS NOT -1 (W=-1 MEANS THAT THE MEMORY FIELD OF THIS
53 INSTR REFERS TO A REGISTER) SEARCH RST TO SEE IF THE
54 NEEDED VALUE IS ALREADY IN A REGISTER (USE BIT ON, W=RSV[I],
55 & REF CNT=0). IF SO, PLACE REF COUNT IN RST[I]. IF THIS OPCODE
56 DOES NOT CHANGE CONTENTS OF REGISTER, TURN ON USE BIT.
57 IF THIS INSTR IS A REGISTER LOAD, AND INSTRUCTION DELETION IS
58 PERMITTED, RETURN 1 TO INDICATE THAT IT SHOULD BE SUPPRESSED.
59 4. SEARCH RST TO FIND A REGISTER WHICH IS NOT IN USE AND
60 WHICH DOES NOT CONTAIN A DORMANT VALUE (USE BIT OFF &
61 REF COUNT=0). IF FOUND, SET USE BIT OF RST[I] ON AND
62 FILL IN REF COUNT FROM RG[R]. SET RSV[I] TO W. SET
63 RG[R] TO -I TO SHOW THAT A REGISTER HAS BEEN ASSIGNED.
64 RETURN.
65 5. FIND ANY AVAILABLE REGISTER (REF COUNT=0). IF NONE EXISTS,
66 ISSUE ERROR MESSAGE AND QUIT, ELSE SET RST, RSV, RG[R] AS
67 IN CASE (4). RETURN.
69 RCHK(I,L,W) I: REGISTER NUMBER
70 L: FUNCTION INDICATOR (SEE BELOW)
71 W: SYMBOL VALUE (SEE BELOW)
72 SEE IF REGISTER I SATISFIES THE CONDITIONS SPECIFIED BY L:
73 L=0 AN REGISTER WHICH CONTAINS THE VALUE W
74 L=1 A REGISTER WHICH DOES NOT CONTAIN A DORMANT VALUE
75 L=2 A REGISTER NOT CURRENTLY IN USE--EVEN IF IT HAS AN OLD VALUE
76 RETURN 1 IF CONDITION SATISFIED, ELSE 0.
78 SVREG(SNO,NCO,NARR,OIW,IW,L) SAVES REGISTERS IN TEMPORARIES.
80 RSREG(NC,OIW,IW) RESTORES REGISTERS FROM TEMPORARIES. #
