46 THE SEMANTIC ROUTINES OPERATE ON ENTRIES IN THE STACK ST, WHICH IS MAINTAINED

48 THE WAY SEMANTIC ROUTINES WORK IS THIS: WHEN COTREE DECIDES THAT A ROUTINE IS
49 TO BE INVOKED, IT SETS UP THE STACK AND CALLS DOSEM. THE STACK POINTER
50 POINTS TO THE FIRST ARGUMENT OF THE PRODUCTION.
51 NOW THE SEMANTIC ROUTINES ARE INVOKED, AS FOLLOWS: PARAMETERS ARE EITHER
52 OBJECTS OR CONSTANTS OR OTHER NAMES. (THE ROUTINES ARE CALLED WITH MINUS

55 USUALLY RETURN A VALUE WHICH IS A STACK POINTER.
