16#THIS IS FILE IMPCHAN, THE CHANNEL INPUT AND OUTPUT OF TOPS-10 THAT THE ORIGINAL'S PROGRAMS CALL AS ROUTINES (INIT, LOOKUP, ENTER, INPUT, OUTPUT, CLOSE, RENAME, RELEAS), OVER THE C LIBRARY'S FILES. THE ORIGINAL'S ARE THE MONITOR'S OWN CALLS: A CHANNEL IS
17 A NUMBER, THE PROGRAM GIVES THE MONITOR A RING OF BUFFERS AND A HEADER (A RING POINTER, A BYTE POINTER AND A COUNT), THE MONITOR FILLS OR EMPTIES A BUFFER AT INPUT OR OUTPUT, AND THE PROGRAM READS OR WRITES THE BYTES ITSELF THROUGH THE POINTER, COUNTING.
18 HERE A CHANNEL IS 0 TO 15 AND HAS ONE BUFFER OF 1024 BYTES OF THE LIBRARY'S, WHATEVER RING THE PROGRAM BUILT (THE ORIGINAL'S RING LINKS ARE 18 BIT ADDRESSES). THE HEADER IS THREE WORDS: THE ADDRESS OF THE BUFFER, THE BYTE POINTER (THE ADDRESS OF THE BYTE BEFORE THE NEXT ONE, FOR A BYTE IS TAKEN WITH THE POINTER ADVANCED FIRST, <+P>, AS THE PDP-10'S ILDB AND IDPB DO), AND THE
19 COUNT, THE BYTES LEFT TO READ OR THE ROOM LEFT TO WRITE. A PROGRAM READS WITH THE COUNT DECREMENTED BEFORE EACH BYTE, CALLING INPUT WHEN IT IS 0 OR LESS (AS THE LEXER OF THE ORIGINAL DOES), AND WRITES BYTES WITH THE POINTER ADVANCED AND THE COUNT
20 DECREMENTED, CALLING OUTPUT WHEN IT IS FULL. NAMES ARE STRINGS (THE EXTENSION IS ADDED AFTER A DOT), AND THE DEVICES ARE DSK (THE FILE SYSTEM) AND TTY (THE STANDARD FILES). A ROUTINE RETURNS 0 FOR SUCCESS, AS THE ORIGINAL'S LOOKUP, ENTER AND INPUT ARE TRUE
21 FOR A FAILURE OR THE END OF THE FILE. NOT PROVIDED: DUMP MODE (A COMMAND LIST), BINARY MODE, THE OTHER DEVICES, USETI AND USETO, AND THE STATUS BITS. THE MODE IS KEPT AND NOT USED: A TEXT IS BYTES (UTF-8) IN EVERY MODE.#
23CHF,CHM,CHO,CHI,CHD,CHB,CHT,CHN ARE 16 LONG; # PER CHANNEL: THE FILE (0 IF NONE), THE MODE, THE OUTPUT AND THE INPUT HEADER, THE DIRECTION (1 INPUT, 2 OUTPUT), THE BUFFER, THE DEVICE (1 DSK, 2 TTY, 0 NO INIT), THE NAME #
24CHP IS 548 LONG; # A FILE NAME: NAME.EXT, 4384 BYTES #
26# CHPATH(NM,EX): THE FILE NAME NAME.EXT IN CHP (NAME ALONE IF THE EXTENSION IS EMPTY) #

29 ELSE CCALL snprintf(LOC(CHP),4384,LOC('%s.%s'),LOC(NM),LOC(EX));
30 0);

40# CHHEAD(CH,K,V): WORD K OF THE HEADER OF THE DIRECTION THE CHANNEL IS OPEN FOR (0 THE BUFFER, 1 THE BYTE POINTER, 2 THE COUNT) IS V #

48# CHOPEN(CH,D,F): THE FILE F, OPENED IN THE DIRECTION D (1 INPUT, 2 OUTPUT) ON CHANNEL CH, WITH ITS BUFFER AND ITS HEADER MADE: THE BYTE POINTER BEFORE THE START, THE COUNT 0 FOR INPUT AND THE WHOLE BUFFER FOR OUTPUT #

50 DD ARE LOCAL;

58 0);
60# INIT(CH,MODE,DEV,OHDR,IHDR): THE CHANNEL CH FOR THE DEVICE DEV WITH THE HEADERS OHDR (OUTPUT) AND IHDR (INPUT); THE ORIGINAL PASSES '0' FOR THE ONE IT DOES NOT USE. 1 FOR A DEVICE THAT IS NOT HERE #
61SUBR INIT(CH,MODE,DEV,OHDR,IHDR) IS (
62 CHA ARE LOCAL;
63 CHA:=CH;

65 CHA>15 => RETURN 1;
66 CHF[CHA] NE 0 => CHFREE(CHA);

69 CCALL strncmp(LOC(DEV),LOC('TTY'),3)=0 => CHT[CHA]:=2;
70 CHT[CHA]=0 => RETURN 1;
71 CHM[CHA]:=MODE; CHO[CHA]:=LOC(OHDR); CHI[CHA]:=LOC(IHDR);
72 0);

96# INPUT(CH,LIST): THE NEXT BUFFER OF THE FILE OF CH IS READ (A LINE FROM THE TERMINAL), THE BYTE POINTER BACK BEFORE THE START OF THE BUFFER AND THE COUNT THE BYTES READ; 1 AT THE END OF THE FILE OR IF THE CHANNEL IS NOT OPEN FOR INPUT (A LIST IS THE ORIGINAL'S DUMP MODE: NOT USED) #
97SUBR INPUT(CH,LS) IS (
98 CHA,N ARE LOCAL;
99 CHA:=CH;

110# OUTPUT(CH,LIST): THE BYTES THE PROGRAM HAS STORED IN THE BUFFER OF CH, FROM THE BUFFER TO THE BYTE POINTER, ARE WRITTEN, AND THE BUFFER IS EMPTY; 1 IF THE CHANNEL IS NOT OPEN FOR OUTPUT OR THE WRITE FAILED #
