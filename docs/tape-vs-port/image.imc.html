3#THIS IS FILE IMAGE, THE SWITCHES U AND V OF THE TAPE'S DRIVER: SAVE THE COMPILER, WITH THE SYNTAX AND THE DECLARATIONS IT HAS COMPILED, SO THAT A LATER RUN STARTS FROM THERE. NOT IN THE TAPE AS A PROGRAM: ON TOPS-10 THE
4 MONITOR'S SSAVE WRITES THE CORE IMAGE OF THE COMPILER; HERE THE LANGUAGE THE COMPILER HAS LEARNED IS WRITTEN TO A FILE: THE FREE STORAGE (THE DIRECTORY, THE SYNTAX GRAPH, THE CODE TREE, THE SEMANTICS ARRAY: ALL THE TABLES),
5 THE VARIABLES OF THE MODULES OF THE COMPILER (THEY ARE LISTED IN THE SECTION IMPVARS, A RECORD FOR EACH, BY THE COMPILER THAT COMPILED THE MODULES: IRVARREC IN SRC/IX.IMC; THE LIBRARY'S IMPVARLIST READS THEM) AND THE
6 TABLE OF THE SEMANTIC ROUTINES BY NAME. THE IMAGE IS FOR THE COMPILER THAT MADE IT: THE VARIABLES ARE MATCHED BY NAME AND THE FILE SAYS IF THE LIST IS NOT THE SAME. THE DRIVER MODULE (IMPM) IS NOT IN THE IMAGE, NOR THE FILE THAT
7 THE LEXER HAS OPEN. THE ARENA IS ASKED FOR WHERE IT WAS SAVED (THE DEFAULT HINT IS ALWAYS THE SAME), BUT THE IMAGE DOES NOT NEED IT THERE: ALMOST EVERYTHING IN THE ARENA IS A WORD INDEX FROM FB, WHICH IS THE SAME WHEREVER THE ARENA
8 LIES, AND THE FEW ABSOLUTE ADDRESSES OF IT ARE MOVED BY THE DIFFERENCE OF THE BASES WHEN THE IMAGE IS LOADED. THE CENSUS OF THE ABSOLUTE ADDRESSES (IMPIMGCENSUS=1 AT THE SAVING PRINTS IT; TESTS/IMAGE/RUN.SH CHECKS IT):
9 - THE WORDS OF THE ARENA (THE DIRECTORY, THE SYNTAX GRAPH, THE CODE TREE, THE SEMANTICS ARRAY, THE STACKS, THE HEADERS OF THE BLOCKS): NONE. THEY HOLD INDICES, NAMES, FLAGS AND PACKED FIELDS. A WORD THAT HAPPENS TO HAVE THE VALUE OF
10 THE BASE (A PACKED FIELD OF 42 IN BITS 40 AND UP IS 2A0000000000 HEX) IS NOT AN ADDRESS: NO WORD OF THE ARENA IS SCANNED OR CHANGED BY THE LOAD.
11 - THE VARIABLES OF THE MODULES THAT THE IMAGE SAVES, FIVE: THE BYTE POINTERS OF THE LEXER INTO ITS LINE AND ITS TOKEN, LEX:PC, LEX:QC, LEX:K0, LEX:K AND LEX:PC0 (THE LINE AND THE TOKEN ARE ARRAYS OF THE ARENA, STEPPED THROUGH BY BYTE
12 POINTERS AS ON THE TAPE: THEY STAY POINTERS). THE LIST IS IMGPTRNAME; THE LOAD ADDS THE DIFFERENCE OF THE BASES TO EACH ONE THAT HOLDS A VALUE OF THE OLD ARENA, ONCE, BEFORE THE LEXER IS USED. FB ITSELF (IMPSEM:FB, THE SAME
13 VARIABLE FOR ALL THE MODULES) IS SET TO THE BASE OF THE NEW ARENA.
14 - THE PARAMETERS AND LOCAL VARIABLES OF ROUTINES (THEIR NAMES START WITH _25PAR OR _25 AND A NAME; THEY ARE STATIC): THE ONES OF FREE AND DIR AND LEX HOLD STALE ADDRESSES OF THE ARENA OR OF THE PROGRAM FROM THE LAST CALL. THEY ARE
15 ALWAYS ASSIGNED BEFORE THEY ARE READ, AND ARE NOT MOVED.
16 - ADDRESSES OF THE PROGRAM (STATIC DATA, CODE, HEAP): NONE IN THE SAVED VARIABLES BUT THE STALE ONES JUST SAID. THE ROUTINES OF THE SEMANTICS ARE SAVED BY NAME (SEMREMAP), THE REGISTRY BY THE NAME OF THE VARIABLE AND ITS OFFSET, THE CACHE
17 OF THE ASSEMBLER NAMES (IX:SYMC, A HEAP ARRAY) IS NOT SAVED AND IS EMPTIED, THE FILE THE LEXER HAS OPEN IS NOT SAVED.
18 THE FILE IS WORDS OF 8 BYTES AND BYTES: THE MAGIC, THE VERSION (6; THE EARLIER ONES NEEDED THE ARENA AT THE SAME ADDRESS AND ARE REFUSED), THE SIZE OF A POINTER, THE
19 BUILD (A HASH OF THE LIST OF VARIABLES), THE ADDRESS OF THE ARENA, HOW MUCH OF IT, THE NUMBER OF VARIABLES AND OF ENTRIES OF THE REGISTRY OF THE ARRAYS THAT MOVE; THE VARIABLES (A LENGTH, THE NAME, THE SIZE, THE BYTES); THE
20 ARENA; THE NAMES OF THE SEMANTIC ROUTINES IN THE ORDER OF THEIR IDS; THE REGISTRY (A LENGTH, THE NAME OF THE VARIABLE THAT POINTS AT THE ARRAY AND THE OFFSET IN IT, THE SECOND WORD OF THE ENTRY).#
